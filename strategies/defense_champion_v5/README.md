# CME MES 九合一量化自動交易策略 v5.0 (雙劍合璧終極防守冠軍版本)

## 策略定位
- **版本號**：`v5.0` (`v5_DualChampion_VWAP_AsymmetricTranches`)
- **策略稱號**：終極防守與卡瑪之王 (The Ultimate Defense & Calmar Champion)
- **回測時間**：連續 5 年（2020-2024 年，1,300 個美股交易日、358,800 根 5m K 線）

## 核心優化模組
1. **日內 VWAP 動態價值濾網 (Session VWAP Dynamic Filter)**：
   - 僅允許現價在當日 VWAP 之上開立好倉、在當日 VWAP 之下開立淡倉。
   - 徹底杜絕逆勢與均值回歸殺傷，勝率提升至 **58.07%**。
2. **不對稱三梯次收割機制 (Asymmetric Tranches 60% / 25% / 15%)**：
   - **第一梯次 (60%)**：1.25R 快攻鎖定本金，觸發立刻移保本 (BE +0.25 pt)。
   - **第二梯次 (25%)**：2.40R 鎖定主升段核心波段利潤。
   - **第三梯次 (15%)**：1.80R 啟動 1.2x ATR 動態移動止損長跑。
3. **規則 2 & 3 箱體震盪限 1 口對沖保護**：避免盤整磨損。
4. **斐波那契浪 3 限價單 (LMT) 掛單接貨**：零滑價保護。
