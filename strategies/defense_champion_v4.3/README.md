## 二、 核心架構與防禦機制

1. **限價單接貨零滑價機制 (`use_limit_orders = True`)**：
   - 在斐波那契回調浪 3（Rule 4）進場時，採用被動限價掛單（`LMT`）在 `0.42 ~ 0.70` 回調位等候撮合，進場滑價為 0 點（每筆省下 $1.25 ~ $2.50 摩擦成本）。
   - 若 3 根 K 棒內未被撮合，自動撤銷掛單（`limit_order_expiry_bars = 3`），絕不追高殺跌。
2. **規則 2 & 3 震盪市嚴格限 1 口對沖 (`max_rule2_3_contracts = 1`)**：
   - 箱體頂沽底揸（Rule 2）與假突破反轉（Rule 3）全天候鎖定僅開 1 口合約。
   - 在 5 年回測中穩定貢獻 **+$160,545 USD** 淨利潤，同時其微小磨損完全不污染規則 4 主力趨勢加碼的索提諾比率窗口（`exclude_r2_r3_from_sortino_rolling = True`）。
3. **CME 原生交易所硬止蝕 (`CME STP PRT`)**：
   - 所有進場單必須直接在 CME 交易所掛單 Native STP PRT 止損，保證遇重大黑天鵝時由芝商所撮合引擎強制平倉，防止本地斷網或斷電時穿倉。
4. **浮盈保護與移動止蝕**：
   - 浮盈達 1.15x ATR 時自動觸發 TP1 減倉 50%，並將剩餘合約移至保本線（Breakeven）。
   - 浮盈達 2.25x ATR 時自動觸發 TP2 減倉 25%。
   - 浮盈達 2.20R 時啟動 **1.50x ATR 移動追蹤止損 (Trailing Stop)** 鎖定 Runner 倉位利潤。
5. **資產階梯滾動控口**：
   - Tier 1 ($30,000 ~ $45,000)：2 / 3 / 5 口
   - Tier 2 ($45,000 ~ $75,000)：2 / 4 / 6 口
   - Tier 3 (> $75,000)：4 / 8 / 12 口
